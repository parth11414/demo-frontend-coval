# devsignal

A live dashboard of the people, projects, and systems shaping modern engineering.

Pure static frontend — no build step, no framework, no server-side rendering.

## Run locally

```sh
npm install
npm run dev      # serves the app at http://localhost:3000
```

## Deploy to Vercel

This is a no-framework static site. Vercel deploys it as a pure static build.

```sh
vercel pull    # choose Vercel Edge / static preview, no framework
vercel deploy
```

The `vercel.json` config sets `framework: none` and serves the static files from the `public/` directory (generated by `npm run build`). The `service-worker.js` cache version is bumped per release so returning visitors pick up new static assets.

Environment variables: none are required for the static demo. If you later enable backend
capabilities, add the secrets (e.g. `GEMINI_API_KEY`) in the Vercel dashboard rather than
hardcoding them.
